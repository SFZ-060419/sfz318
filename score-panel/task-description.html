1等级一 · 基础L1

面向：刚学完 getElementById / querySelector、数组遍历与基本高阶方法的学生。聚焦 核心 DOM 查找 + 基础数组方法，完成 5 个功能。

需完成的功能（5 项）

  1. 班级概览统计：班级人数、总分、平均分、及格率 → 写入 4 张统计卡
  2. 学生卡片列表渲染：遍历数据生成卡片（头像 / 五科分数 / 总分均分 / 排名）
  3. 不及格预警：筛选有不及格科目的学生，按不及格数排序展示
  4. 搜索：按姓名或学号实时过滤
  5. 排序：按总分降序 / 按学号升序切换

2等级二 · 进阶L2

面向：已掌握基础 DOM 操作、希望深入 节点关系遍历、动态/静态集合差异、高阶数组方法 的学生。在等级一基础上新增 6 项，共 11 项功能。

等级一全部功能 + 以下新增（6 项）

  1. 各科平均分对比：每科用 reduce 求平均，渲染进度条（style 操作宽度）
  2. 优秀学生 Top3：filter（平均≥85）→ sort → slice(0,3)
  3. 各科状元榜：遍历科目用 reduce 找最高分者
  4. 筛选切换：全部 / 优秀 / 含不及格 —— 考察 getElementsByClassName 动态集合 vs querySelectorAll 静态集合
  5. 点击卡片展开详情：事件委托 + closest + 节点关系（lastElementChild）+ classList.toggle
  6. 班级状态提示：some / every 判断是否有不及格 / 是否全员优秀

考察点（在等级一基础上扩展）

类别新增 / 强化的知识点
DOM查找getElementsByClassName（动态集合）、节点关系（parentNode、children、firstElementChild、lastElementChild、nextElementSibling）、closest、classList.toggle、style、动态 vs 静态集合的遍历差异
数组方法新增 find、some、every；综合 filter→sort→slice→map 链式处理
函数高阶函数（函数作为参数传入 forEach/map/sort）、纯函数与副作用分离、事件委托模式
⚠ 易错点提醒：getElementsByClassName 返回的是动态集合，遍历移除类名时不能直接 forEach（长度会变），需用 while(list.length)；而 querySelectorAll 返回静态集合，可安全 forEach。这正是本任务的故意考察点。

4使用 Trae IDE 完成任务

本任务要求使用 Trae（AI 集成开发环境）辅助完成，锻炼“用自然语言驱动开发”的能力。

  1. 打开项目：在 Trae 中打开本任务所在文件夹，用浏览器先打开 target.html 观察目标效果与交互（搜索、排序、点击卡片展开）。
  2. 选择难度：根据自身水平打开 starter-level1.html 或 starter-level2.html，阅读其中 <script> 内的 TODO 注释与函数壳。
  3. 用 Trae 辅助：选中某个 TODO 函数，在 Trae 对话框中描述需求，例如：“帮我实现 renderStats 函数，用 reduce 求总分，filter 求及格人数，写入 4 个统计卡片”，让 AI 生成代码后粘贴/接受。
  4. 逐函数验证：每完成一个函数就刷新浏览器，与 target.html 对应区域逐像素对照，不一致再让 Trae 调整。
  5. 理解为主：对 AI 生成的每一行，要求自己能讲清“为什么这么写”。可用 Trae 选中代码追问“这行为什么用 reduce 不用 for 循环”。
  6. 提交：完成后保存文件，按教师要求提交 starter-levelX.html（data.js 无需改动可一并提交）。
💡 给 Trae 的提问模板：“当前函数 xxx 的作用是…，数据来自 window.STUDENTS，请用 reduce 实现，并把结果写入 id 为 yyy 的元素，注意保持与 target.html 一致的 DOM 结构。”

6知识点速查（对照 target.html 注释）

DOM 查找

  • getElementById：定位统计卡
  • querySelector：单元素（进度条 i）
  • querySelectorAll：静态集合（排序按钮）
  • getElementsByClassName：动态集合（筛选按钮）
  • createElement / appendChild：建卡片
  • closest：事件委托找卡片
  • lastElementChild：节点关系找详情区
  • classList：toggle / add / remove

数组方法

  • forEach：遍历渲染
  • map：数据映射、生成 DOM 串
  • filter：筛选不及格 / 优秀
  • reduce：求总分、求平均、找状元
  • sort：排名、不及格数排序
  • slice：取 Top3
  • some / every：班级状态判断
