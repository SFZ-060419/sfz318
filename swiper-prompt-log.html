Swiper 轮播课堂任务

任务一：两轮提示词迭代（含首轮遗漏与修正）｜任务二：creative 电影墙答辩｜任务三：超纲能力 keyboard 答辩

任务一 · 提示词工程师目标：new Swiper('#mySw4', {...}) 满足四条需求

需求原文四条：① 无缝循环　② 3.2 秒自动翻页且手动操作后不停止　③ 圆点分页器可点击　④ 初始效果为 cube。下面是两轮真实迭代过程。

第 1 轮提示词（口语化，只说了"大概"）

我的第 1 轮提示词帮我写一个 Swiper 的初始化配置，要能循环播放，还要自动翻页，翻页间隔 3.2 秒，另外要有分页小圆点，效果用 cube 立方体。
AI 第 1 轮回答（原文照录） 
var mySw4 = new Swiper('#mySw4', {
  loop: true,
  effect: 'cube',
  autoplay: { delay: 3200 },
  pagination: { el: '.swiper-pagination' }
});

可以循环、可以 3.2 秒自动翻页、初始是 cube，分页器也给了。

⚠️ 把这段代码粘进页面后，发现 3 处不对
  • 漏了"手动操作后不停止"：只写了 delay，用户拖一下之后自动播放就永久停了——因为 disableOnInteraction 默认为 true。
  • 漏了"圆点可点击"：pagination 有 el 但没写 clickable: true，圆点只能看不能点。
  • el 写错：写成了全局类选择器 .swiper-pagination，页面上有四组轮播，这个选择器会命中第一个而不是 #mySw4 自己的分页器，圆点会挂错位置。

第 2 轮提示词（逐条点名，把隐含条件写成显式条件）

我的第 2 轮提示词上一版有 3 个问题，请按下面逐条改： 1. 我用鼠标拖动轮播之后，自动播放不能停，要继续翻下一页（这个必须做到）； 2. 下面的圆点要能点，点哪个就跳到哪一张； 3. 分页器的 el 不要用类选择器，我这个页面有四组轮播，必须精确指定到我自己的 #myPag4； 4. 初始效果保持 cube，间隔 3.2 秒、无缝循环这两条不变。 只给我可以直接粘贴使用的完整配置。
AI 第 2 轮回答 → 已落地到页面（swiper-task.html 底部脚本） 
var sfz_mySw4 = new Swiper('#mySw4', {
  loop: true,                                        // ① 无缝循环
  effect: 'cube',                                    // ④ 初始立方体
  cubeEffect: { shadow: true, slideShadows: true },  // 立方体的阴影与面片明暗
  autoplay: {
    delay: 3200,                 // ② 3.2 秒一翻
    disableOnInteraction: false  // ② 手动拖动后自动播放不停止
  },
  pagination: {
    el: '#myPag4',               // 精确到本组，不误伤其它轮播
    clickable: true              // ③ 圆点可点击跳转
  }
});

逐项验证（每条都亲手粘贴进页面点过）

需求验证动作结果
① 无缝循环停在最后一张继续往后翻，回到第一张无空白、无跳回通过
② 自动 + 不停等 3.2 秒自动翻一张；再用鼠标拖动一次，之后仍继续自动翻通过
③ 圆点可点点第 4 个圆点，直接跳到第 4 张（奋斗者号）通过
④ 初始 cube刷新页面，第一眼就是 3D 立方体翻转，不是平推通过

一句话结论：第 1 轮只覆盖了"看起来像"的需求，漏掉的两个都是默认值陷阱（disableOnInteraction 默认 true、clickable 默认 false）；第 2 轮把"手动后不停""能点"写成显式条件，并要求固定 el 后，四项全部达成。

任务二 · creative 仿写答辩课堂没讲过的第 7 种效果

我读官方示例后写的配置（演示四第 7 个按钮）

creativeEffect 片段 
if (sfz_effect === 'creative') {
  sfz_opt.creativeEffect = {
    prev: { shadow: true, translate: ['-120%', 0, -500], rotate: [0, 0, -20] },
    next: {                    translate: ['120%', 0, -500], rotate: [0, 0,  20] }
  };
}

prev / next 的 transform 各控制什么

参数含义
prev描述已经划过去的那一张停在什么姿态：它离开视野后往哪去、多大多斜。
next描述还没轮到的那一张在什么姿态待命：它从哪里进场、多大多斜。
translate三元素数组 [x, y, z]：水平位移、垂直位移、纵深位移（px）。
rotate三元素数组 [x, y, z]：绕三条轴的旋转角度（deg）。第三位就是"卡片在屏幕平面内歪多少度"。
shadow是否给该张加投影，用来制造"两张卡片前后错开"的层次。

答辩：百分号是相对谁的？相对轮播容器（swiper 元素）自身的宽/高，不是相对图片。所以 -120% 是"往左挪出一整个容器再多一点"，换成别的尺寸的容器也会等比例退场。z: -500 是像素，会把卡片往屏幕里推远，视觉上变大变小的透视感就来自这里。

答辩：改一个数值让卡片转 20 度？rotate 的第三位就是绕 Z 轴（屏幕法线）的角度，当前 prev 写的就是 -20、next 是 20——即左右两张各自反方向歪 20 度，所以叠起来像两面斜插的电影幻灯片。把它改成 0 卡片就正着进出，改成 45 倾斜会明显夸张。

任务三 · 综合创作答辩第六件展品 + 课堂没讲的 Swiper 能力

① 第六件展品：爱达·魔都号

用 AI 生成横版 16:9 主图（swiper-imgs/aida_modu_1.jpg），slide 结构与其余五件完全一致（img + .wy-cap 标题与配文），四个轮播组都补上了这一张，保证"六件展品"在任何一组里都成立。

② 我选的超纲能力：keyboard 键盘控制

演示四的扩展配置 
keyboard: { enabled: true, onlyInViewport: true }

这段代码什么意思？enabled: true 开启键盘控制，方向键 ← → 就能翻页；onlyInViewport: true 表示只有这组轮播滚动到可视区域内时才响应按键，页面滚动到别处时不抢键盘，避免用户想上下滚页面却在偷偷翻轮播。

AI 第一次给的哪里不对？AI 首版只给了 keyboard: true——这在 Swiper 11 里不生效，参数已经改成对象形式；而且它没提"容器必须可聚焦"。我在 #wySw4 上加了 tabindex="0" 才能用 Tab 聚焦后接收方向键。

新参数的作用 + 现场改 delay：autoplay.delay 是每张图停留的毫秒数，当前 3200（3.2 秒）。若现场改成 delay: 1000，翻页节奏会明显变快，1 秒一张，六张一圈只需 6 秒，观感从"从容浏览"变成"快速掠过"。

disableOnInteraction: false 再解释一次：它决定"用户手动操作之后自动播放是否继续"。默认 true 会在拖动后停止，设为 false 才能做到拖动完仍自动往下翻。
